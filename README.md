# 🛒 Superstore Sales Dashboard

## 📌 Project Overview
An interactive sales dashboard built using Tableau Public 
analyzing 10,000+ US retail transactions from the Superstore dataset.

## 🛠️ Tools Used
- Tableau Public
- Sample Superstore Dataset (built into Tableau)

## 📊 Charts Built
- Monthly Sales Trend (Line Chart)
- Sales by Category (Bar Chart)
- Top 10 Products by Profit (Bar Chart)
- Profit by State (Map)

## 🔍 Key Insights
1. Technology is the highest selling category
2. Canon imageCLASS is the most profitable product
3. Sales peak every year in Q4 (October - December)
4. Some states show negative profit despite high sales
